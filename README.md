## 复习范围

1. **极限与连续**：等价无穷小、幂式极限、数列、洛必达法则和间断点。
2. **导数与微分**：分段点可导性、复合与隐函数、参数曲线、高阶导数和曲率。
3. **定理与应用**：中值定理、泰勒公式、单调性、极值、凹凸性和渐近线。

复习时可以先看例题的题目和“从哪里下手”，动手算完后再对照推导。
